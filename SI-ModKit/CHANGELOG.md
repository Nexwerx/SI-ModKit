# Changelog

This file records **public-facing releases**. Historical alpha milestone reports from the original development archive are retained under [`Documentation/Development-History`](Documentation/Development-History), not mixed into release notes.

## 1.0.0 — Initial public package

- Native-style in-game visual UI builder with multi-window projects, templates, and live preview.
- Named saved projects, undo/redo, portable project text import/export, and whole-project C# generation.
- Controls for text, choices, actions, progress, lists, tables, and confirmation dialogs; row and section layouts.
- Configurable window presentation and named actions/events.
- Typed `SIModKit.UI` / `UIWindow` facade and copyable standalone source kit.
- Optional Unity `SIModKit.Bridge` message transport for advanced cross-mod interaction.
- Known limitation: some initial native previews need a manual **Preview / Refresh** to settle layout.

### Repository preparation

- Organized original source, reference documentation, dev kit and examples for public GitHub distribution.
- Replaced environment-specific deployment guidance and the unsupported cross-assembly example with consumer-facing guidance.
- Retained legacy design/milestone notes as historical material.
