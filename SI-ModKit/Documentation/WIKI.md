# In-game Wiki

The builder includes an in-game Wiki covering project creation, window settings, palette controls, layout, actions, preview, export/import, and C# generation. It is a helpful quick reference while editing.

For searchable, file-based help outside the game, start with [Getting Started](GETTING-STARTED.md) and [Builder Guide](BUILDER-GUIDE.md). More technical topics are linked from the [documentation index](README.md).
