# Examples

`StandaloneWindow.cs.txt` is a self-contained **method/class snippet** illustrating use of the copied DevKit facade after the game UI has initialized. It is deliberately not a complete installable mod: attach its invocation to your own mod lifecycle.

The original archive included an example that suggested compiling directly against a separately installed toolkit DLL. That pattern is **not supported** for independently compiled source mods and has been replaced here.

See [Integration](../Documentation/INTEGRATION.md) and [API](../Documentation/PUBLIC-API.md).
